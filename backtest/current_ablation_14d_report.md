# Current-engine 14-day ablation report

## Scope

This is a side experiment on the same 14-day cTrader M5 dataset. No production strategy code or runtime configuration was changed.

Dataset period: `2026-09-13T21:40:00+00:00` to `2026-09-25T20:55:00+00:00`.

Current restored configuration included:

- `m5_confirmation_mode: BOS_AFTER_CHOCH`
- `allow_weak_structure: false`
- `require_poi_confluence: true`
- `require_displacement: true`
- `min_displacement_ratio: 1.0`
- `min_rr: 2.5`

## Current-engine ablations

Each row changes one setting only; all other settings remain at the current baseline.

| Case | Change | Selected opportunities | Equal trades | Adaptive trades | Result |
|---|---|---:|---:|---:|---|
| Baseline | None | 0 | 0 | 0 | No signals |
| No POI confluence | `require_poi_confluence=false` | 0 | 0 | 0 | No signals |
| CHOCH or BOS | `m5_confirmation_mode=CHOCH_OR_BOS` | 0 | 0 | 0 | No signals |
| Weak structure | `allow_weak_structure=true` | 0 | 0 | 0 | No signals |

The direct evaluation diagnostics show the dominant rejection families are still:

- `H1_STRUCTURE_UNCLEAR`
- `H1_POI_NOT_FOUND_IN_LOCATION`
- `H1_POI_CONFLUENCE_INSUFFICIENT`

Therefore, none of the three individual switches is the sole blocker. The current engine is not reaching a valid signal under these one-factor changes.

## Existing RR/trailing evidence

An older, separately generated 14-day BOS/liquidity-regime cache contains 17 selected opportunities. Its archived results were:

| Conservative trail after 1.5R | 9 | 77.78% | 4.5412 | 1.3586 | 0.6802% | 0.1132% |

`TRAIL_1_5R` was the strongest of those archived exit variants, but it was evaluated on a different historical signal cache. It is not yet validated against signals generated by the current engine.

## Conclusion

Do not apply these settings to production yet. The ablation result is a reproducibility/gating failure, not a performance result: zero trades means no PF, win rate, or R comparison is statistically meaningful. The next diagnostic should isolate the H1 structure/POI pipeline and compare its intermediate artifacts against the archived 17/24 selected signals before testing exit settings again.
